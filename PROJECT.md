# epub2docx-by-jair-lima

## Descrição
Conversor de EPUB para DOCX em formato A5, pronto para impressão de livro físico.

## Stack
Python 3, python-docx, BeautifulSoup, lxml, Pillow; pywin32 opcional (atualiza o sumário pelo Word).

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`python epub2docx.py livro.epub livro.docx`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
